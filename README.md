# Leaflet Part 1: Earthquake Visualization
GitHub Page deployment link: https://lavenya-mohan.github.io/leaflet-challenge/



This project visualizes earthquake data using Leaflet.js and D3.js. The map shows earthquakes from the past week, with markers sized according to magnitude and colored according to depth. Each marker includes a popup displaying additional information about the earthquake.

## Features:
- Interactive map displaying earthquakes using Leaflet.js.
- Markers sized based on earthquake magnitude.
- Markers colored based on the depth of the earthquake.
- Popups displaying earthquake details (magnitude, location, and depth).
- A legend indicating depth and its corresponding color.

## Technologies:
- **Leaflet.js**: A leading JavaScript library for interactive maps.
- **D3.js**: A JavaScript library for manipulating documents based on data (used for fetching and visualizing GeoJSON data).
- **HTML/CSS**: To structure and style the webpage.
